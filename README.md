### 🚀 Featured project
**[NYC Housing × Traffic Safety Dashboard](https://github.com/ZiadMoharam6/nyc-dev-dashboard)**: is New York's new affordable housing being built on more dangerous streets?
- Integrated **1.5M+ crash records** with NYC affordable-housing data (ZIP × year join + 250 m spatial linkage)
- Recovered missing ZIP codes with **k-NN** instead of dropping a third of the data
- Multi-page **Dash / Plotly** dashboard with filters, free-text search and CSV export, deployed on Render
- Key finding: housing-heavy ZIPs rank higher for injuries (r = 0.56), yet saw injuries fall the most (−12.5%)

🔗 [Live dashboard](https://nyc-dev-dashboard.onrender.com) *(free tier, first load takes ~50 s)*
